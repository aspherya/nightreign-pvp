NIGHTREIGN PVP - HOW TO INSTALL
===============================

You need: ELDEN RING NIGHTREIGN on Steam, with Seamless Co-op already installed.


INSTALL (one time)
------------------
1. Open your game folder.
   In Steam: right-click ELDEN RING NIGHTREIGN > Manage > Browse local files,
   then open the "Game" folder.
   You are in the right place if you can see "nightreign.exe" and "nrsc_launcher.exe".

2. Drag these two things from this zip into that folder:

      nrpvp_launcher.exe
      NightreignPvP          (the whole folder)

That's it.


PLAY
----
1. Start Steam.
2. Double-click "nrpvp_launcher.exe" in the game folder.
   (Tip: right-click it > Send to > Desktop to make a shortcut.)
3. The game starts. Play with your friends through Seamless Co-op as usual:
   one player hosts, the others join.
4. When the expedition begins, the other players are your rivals. You can fight them.
5. A small "BATTLE ROYALE" label appears in the corner of the screen. It shows your
   team and how many rivals you have. It cannot be turned off.

Everyone who started the game with nrpvp_launcher.exe is in this mode.
Everyone in the session must start the game with nrpvp_launcher.exe.


IMPORTANT
---------
* To play the normal game, start it from Steam as always.
  Only use nrpvp_launcher.exe for PvP sessions with friends who also have this mod.
* All players need the same version of this mod and of Seamless Co-op.
* Windows may ask "Do you want to run this file?" the first time. Choose Run.
  If Windows shows a blue "Windows protected your PC" box: click "More info", then "Run anyway".


IF SOMETHING GOES WRONG
-----------------------
* A message says the launcher must be in the game folder:
  you put the files in the wrong place. Go back to INSTALL, step 1.
* A message says Seamless Co-op was not found: install Seamless Co-op first.
* The game does not start: make sure Steam is running, then try again.
* Still stuck? Send the "logs" folder that is inside "NightreignPvP"
  to the person who gave you this mod.


UNINSTALL
---------
Delete "nrpvp_launcher.exe" and the "NightreignPvP" folder from the game folder.
Nothing else was changed.
